## 🚀 Как запустить в Production

### 1. Подготовка окружения
```bash
# Установка зависимостей
npm install

# Создание production build
npm run build

# Запуск production сервера
npm start
```

### 2. Настройка переменных окружения
Создайте `.env.local`:
```env
NEXT_PUBLIC_SOLANA_NETWORK=mainnet-beta
NEXT_PUBLIC_SOLANA_RPC=https://api.mainnet-beta.solana.com
NEXT_PUBLIC_JUP_ENABLE_SEND=true
NEXT_PUBLIC_AI_API_URL=https://ai.aqyldy.com
NEXT_PUBLIC_SOCIAL_API_URL=https://api.aqyldy.com
```

### 3. Деплой на Vercel (Рекомендуется)
1. Подключите GitHub репозиторий к Vercel
2. Настройте переменные окружения в Vercel Dashboard
3. Деплой автоматически при push в main ветку

### 4. Альтернативные платформы
- **Netlify**: `npm run build && netlify deploy --prod`
- **AWS Amplify**: Подключите репозиторий к Amplify
- **Railway**: `railway up`
